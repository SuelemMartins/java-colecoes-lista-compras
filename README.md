## 🎯 Aprendizados

Durante o desenvolvimento deste projeto, aprendi na prática como:

- Criar e manipular listas de objetos em Java;  
- Ordenar elementos usando a interface `Comparable`;  
- Organizar o código em múltiplas classes;  
- Exibir informações de forma estruturada e amigável para o usuário;  
- Utilizar a entrada de dados com `Scanner` para tornar o programa interativo.  

Foi uma experiência que realmente reforçou meu entendimento sobre **coleções de dados** e me mostrou o quanto o Java é poderoso quando o assunto é organização e controle de informações! 🌟
